# Launch checklist

For the public launch of The Fantastical Logic Grid as a free game with
optional extras (see [FREEMIUM.md](FREEMIUM.md)). Mobile apps are paused and
left out. Tick each line as you go.

## Before launch

- [ ] The website https://thelogicgrid.com loads, starts a puzzle, saves, prints and solves.
- [ ] The Windows installer from https://github.com/bltaylorjr/fantastical-logic-grid/releases/latest installs and opens. Windows SmartScreen shows "Windows protected your PC" because the installer isn't code-signed: choose **More info > Run anyway**.
- [ ] The desktop app offers an update when a newer release is out (Menu, home screen).
- [ ] Sign in to the admin dashboard https://flg-api.btay74.workers.dev/admin/ with your game account.
- [ ] Admin **Settings and switches**: check Races, Solo scores, Screen names, Ideas and problems, Celebrations and the voice caps.
- [ ] Admin **Settings and switches > Support and premium**: leave off, or switch on with your support page link once you've picked an option.
- [ ] Post a welcome announcement in admin **Announcements** for launch day.
- [ ] Work through the setup emails still open (subjects start "To do:"), most of all the Firebase key check, the email switch and the security settings.
- [ ] Google Search Console and Bing Webmaster: sitemap `https://thelogicgrid.com/sitemap.xml` submitted.
- [ ] The nightly maintenance email arrives only when there's a problem, and the weekly summary email arrives on Monday.

## Launch day

- [ ] Share the promo videos: `the-fantastical-logic-grid-promo-16x9-captioned.mp4` for YouTube and Facebook, and `the-fantastical-logic-grid-promo-9x16-captioned.mp4` for Shorts, Reels and TikTok. Use the matching thumbnail. Don't mention app stores while mobile is paused.
- [ ] Link to https://thelogicgrid.com and to the daily puzzle page.
- [ ] Watch the admin dashboard Overview and Errors pages through the day.
- [ ] Keep an eye on free limits (admin alerts warn at the level set in Alerts and reports).

## The first week

- [ ] Read Ideas and problems every day. Mark fixed items **Addressed** with a note so players who opted in hear back.
- [ ] Check Ratings and insights for puzzles that need attention.
- [ ] Read the Monday weekly summary and the improvement email.
- [ ] Decide on the optional extras and payment option (FREEMIUM.md), if not done yet.
