**Why:** You asked for every public email on the website and social media to be support@thelogicgrid.com. The website, the game, the terms, privacy and educator pages, the ads and the emails players get already use it (or the no-reply address, which stays as it is). What's left are a few settings on other sites that only you can change. Mail sent to support@ still lands in fantasticallogicgrid@gmail.com, so you lose nothing.

Keep signing in to every site with fantasticallogicgrid@gmail.com (or btay74@outlook.com where you already do). Only the email that the public sees changes.

## What to change (each takes a minute)

1. **Facebook Page** (already live): open your Page, then **Edit Page info** (or **Settings > Page setup > Contact info**). Change the email to `support@thelogicgrid.com` and save. <https://www.facebook.com/pages/?category=your_pages>
2. **Firebase sign-in emails** (players see this if they reply to a "confirm your email" or "reset password" email): <https://console.firebase.google.com/project/the-fantastical-logic-grid/authentication/emails>. Edit each template, set **Reply to** to `support@thelogicgrid.com`, and save. Skip it if you never set a Reply to.
3. **Stripe public details** (only if you already set them up): <https://dashboard.stripe.com/settings/public>. Set **Support email** to `support@thelogicgrid.com` and save.
4. **Any new account from here on** (Instagram, Threads, X, Bluesky, LinkedIn Page, YouTube, TikTok, Pinterest, Reddit, itch.io, Microsoft Store, Google Play, Ko-fi): when a profile asks for a **contact**, **business** or **support** email that the public can see, type `support@thelogicgrid.com`. The sign-up (login) email stays the Gmail.
