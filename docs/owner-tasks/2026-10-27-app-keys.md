# Switch on app keys for the Windows and Android apps (about 3 minutes, free)

**Why:** the Windows and Android apps can now ask for an app key the first
time they open. They stay open without a key until the game's server has its
signing key, so nothing changes for players until you do this. The website
never needs a key.

The rules you set: every key and its installs are listed in the admin app
under **App keys**. A key installs on one computer or phone, or two when you
allow it, and can be used for 2 downloads from the website before a new key
is needed.

The signing key is in the project's shared files, in the folder
`fantastical-logic-grid-app/.private`. It is private: don't email it or post
it anywhere else.

**Steps:**

1. In the Claude project, open the **Library** (project files), go to
   `fantastical-logic-grid-app/.private`, and download `license-signing.jwk`.
   Keep it with the other files from that folder somewhere safe: if it is
   lost, a new one means every player types their key again.
2. Open the file in Notepad, press Ctrl+A, then Ctrl+C. It is one line that
   starts with `{"kty":"EC"`.
3. Open https://dash.cloudflare.com/?to=/:account/workers/services/view/flg-api/production/settings
   (Cloudflare > **Workers & Pages** > **flg-api** > **Settings** >
   **Variables and Secrets**).
4. Click **Add**. Type: **Secret**. Name: `LICENSE_SIGNING_KEY`. Value: paste
   the line. Click **Deploy**.
5. Open the admin app at https://flg-api.btay74.workers.dev/admin/#licenses
   (**App keys**). The banner should now say keys are on. Click **Make keys**
   to make one for yourself, and type it into the Windows app the next time
   it opens.

**Your switches** (admin > **Settings and switches** > **App keys**):

- **The apps need a key** (on).
- **Downloads on the website ask for a key** (on).
- **Who can get a key for themselves**: any signed-in player, only Supporters,
  or nobody (only keys you make).
- **Computers or phones each new key installs on**: 1 (you can allow 2 for one
  key under App keys when a player asks).

**Good to know:** the app files on GitHub can still be downloaded directly,
but they won't open without a key. Apps already installed will ask for a key
after they update to the new version.
